# 📝 Historias de Usuario

## Historias de la primera versión

| ID | Historia de usuario |
|---|---|
| **HU01** | Como superadministrador, quiero registrar negocios y asignar a su administrador, para habilitar el servicio a cada dueño. |
| **HU02** | Como administrador de cadena, quiero gestionar sucursales, asignar turnos de trabajo al personal y definir sus permisos, para organizar la atención de mis locales. |
| **HU03** | Como administrador de cadena, quiero gestionar productos con precio, imagen y código de barras opcional, para mantener un catálogo compartido. |
| **HU04** | Como empleado / cajero, quiero consultar existencias y registrar entradas, mermas y ajustes según mis permisos, para controlar y explicar el inventario de mi local. |
| **HU05** | Como empleado / cajero, quiero registrar el envío de productos entre ubicaciones y registrar las cantidades recibidas según mis permisos, para abastecer los locales y detectar diferencias. |
| **HU06** | Como empleado / cajero, quiero abrir mi sesión de caja al iniciar la atención de mi turno, registrar ventas y cerrarla comparando los cobros con el efectivo contado, para controlar el dinero bajo mi responsabilidad. |
| **HU07** | Como administrador de cadena, quiero registrar retiros y entregas de efectivo, para conocer cuánto se retiró y cuánto queda pendiente. |
| **HU08** | Como administrador de cadena, quiero consultar reportes por periodo y sucursal, para supervisar ventas, inventario y caja de mis locales. |
| **HU09** | Como empleado / cajero, quiero registrar el fraccionamiento de tortas según mis permisos, para vender porciones sin duplicar existencias. |
| **HU10** | Como empleado / cajero autorizado, quiero anular ventas con un motivo, para corregir operaciones conservando su historial. |
| **HU11** | Como usuario autorizado, quiero iniciar y cerrar sesión y recuperar mi acceso de forma controlada, para utilizar únicamente las funciones que me corresponden. |
| **HU12** | Como administrador de cadena, quiero consultar el historial de operaciones por empleado y sucursal, para explicar diferencias y supervisar correcciones. |
| **HU13** | Como empleado / cajero autorizado, quiero identificar los lotes próximos a vencer y registrar sus bajas, para evitar vender productos vencidos y controlar las mermas. |
