# Restricciones

Identificar las **restricciones** que condicionan las decisiones de diseño y arquitectura del sistema.

| ID | Restricción | Descripción |
|---|---|---|
| RC01 | **Aplicación web** | El sistema debe ser accesible desde navegador en escritorio o tablet. |
| RC02 | **Control de versiones** | La documentación y el código deben gestionarse mediante Git en un repositorio del proyecto. |
| RC03 | **Servicio multi-tenant** | Una plataforma debe atender varios negocios, manteniendo separada su información. |
| RC04 | **Alcance inicial** | La primera versión cubre gestión interna. Pasarela de pagos y facturación electrónica no forman parte de esta versión. |
| RC05 | **Conectividad** | La primera versión requiere conexión para confirmar operaciones; no implementa ventas sin conexión. |
