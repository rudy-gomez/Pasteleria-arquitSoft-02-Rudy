# 🧁 Plataforma SaaS de Gestión y Pedidos para Pastelerías Multi-Sucursal

Plataforma SaaS multi-tenant para la gestión integral de pastelerías
(catálogo, inventario, traslados entre sucursales, turnos, empleados y caja)
y su canal de pedidos, permitiendo que cadenas y pastelerías independientes
operen de forma autónoma bajo una misma infraestructura.

---

## 👤 Integrante
- GOMEZ BELLIDO, Rudy

## 📖 Descripción
Proyecto académico desarrollado para el curso de **Arquitectura de Software
[IS-488]**, que aborda el análisis del sistema (actores, historias de
usuario, requisitos, atributos de calidad, restricciones y drivers
arquitectónicos) y una primera propuesta de arquitectura en capas, con
énfasis en el control de concurrencia en el descuento de stock y el
modelo multi-tenant.
