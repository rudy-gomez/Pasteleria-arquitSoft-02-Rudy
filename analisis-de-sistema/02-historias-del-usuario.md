# 📝 Historias de Usuario

## Objetivo
Describir las principales necesidades de los usuarios utilizando el formato:
**Como [actor], quiero [acción], para [beneficio].**

---

| ID | Historia de usuario |
|---|---|
| **HU01** | Como superadministrador, quiero registrar nuevas cuentas de pastelería o cadena, para incorporar nuevos clientes a la plataforma. |
| **HU02** | Como administrador de cadena, quiero registrar mis sucursales con su dirección y horario, para gestionarlas de forma independiente. |
| **HU03** | Como administrador de pastelería, quiero registrar el catálogo de productos con su precio y stock, para mantener la información actualizada. |
| **HU04** | Como administrador de pastelería, quiero recibir alertas cuando un producto esté por debajo del stock mínimo, para reabastecerlo a tiempo. |
| **HU05** | Como administrador de cadena, quiero registrar traslados de mercadería entre sucursales, para mantener el inventario sincronizado. |
| **HU06** | Como administrador de pastelería, quiero asignar empleados a turnos, para organizar la operación diaria. |
| **HU07** | Como empleado, quiero registrar una venta en mostrador, para descontar el stock correspondiente. |
| **HU08** | Como empleado, quiero cerrar caja al final de mi turno desglosando los montos por método de pago, para mantener trazabilidad. |
| **HU09** | Como cliente, quiero consultar el catálogo y generar un pedido desde el sitio web, para reservar productos sin necesidad de ir a la tienda. |
| **HU10** | Como administrador de cadena, quiero visualizar reportes consolidados y por sucursal, para tomar decisiones de negocio. |
